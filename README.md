# UK Road Traffic Accident Analysis (2005–2015)

### Tools

Power BI | Power Query | DAX

### Dataset

UK STATS19 Road Safety Data

### Records

~2 million accident records

## Project Overview

* Cleaned and transformed multi-year accident datasets using Power Query
* Decoded and standardised categorical variables including accident severity, weather conditions, lighting and road conditions
* Created DAX measures to calculate accident counts, severity percentages and trend metrics
* Designed an executive-style dashboard focused on accident trends and risk analysis

## Key Insights

* Serious or fatal accidents accounted for approximately 15% of recorded incidents
* Overall accident volume declined steadily between 2005 and 2015
* Rural accidents were less frequent but generally more severe than urban accidents
* Higher speed limits were associated with increased accident severity

# Call Centre Operational Analysis & Performance Dashboard

### Tools

Power BI | Power Query | DAX

### Dataset

Call Centre Operations Dataset (Kaggle)

### Records

~1,200 daily operational records

## Project Overview

* Cleaned and transformed operational data, including standardising time-based fields for analysis
* Developed DAX measures to calculate KPIs such as abandonment rate, answer rate and service level
* Built an interactive dashboard to analyse operational performance and identify trends
* Used visualisation techniques to explore relationships between call volume, wait times and service outcomes

## Key Insights

* Increased wait times were strongly linked to higher call abandonment
* Higher call volumes correlated with reduced service levels, suggesting operational capacity constraints during peak periods
* Recent operational periods demonstrated improved service performance and reduced abandonment rates
* Findings suggested that optimising staffing during peak demand could significantly improve operational outcomes
